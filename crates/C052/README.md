# `tensor_product_module` (C052)

Tier 5 — Tor functor. *Generated from the crate source; regenerate after API changes.*

Tensor products `M ⊗_Z N` of finitely generated abelian groups.

`M ⊗ N` is generated by `m_i ⊗ n_j` subject to relations. For
presentations `M = Z^m / im A` and `N = Z^n / im B`, the relations are
`A_c ⊗ n_j` for every relation column `A_c` of `M` and generator `n_j`, and
`m_i ⊗ B_c` for every generator `m_i` and relation column `B_c` of `N`.
 computes the resulting group
exactly with Smith normal form.
